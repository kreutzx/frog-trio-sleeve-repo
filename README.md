## What it does

`main.py` (Python 3.13, standard library only) writes the album title and
back-cover blurb for a jazz trio made entirely of frogs to
`/output/entry.txt` — 367 characters, inside the competition's 1–400
character gate.

The entry is titled **"Pondwater Blue"**: a live set from the Lily Pad Club,
played straight — Marlowe on tenor sax, Bea on upright bass, Tad on brushes —
three frogs, one late set, and the blues the way they were meant to be played.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
